Built around a real workflow

From a document to a decision.

Knowledge with boundaries

Company roles, teams and restricted spaces control access to versioned PDF, DOCX and text documents. Permissions are checked again when evidence is opened.

Answers you can inspect

Hybrid keyword and vector search finds passages. Local models answer with citations to the exact document version, with follow-ups saved in private conversations.

A complete workspace

Personal accounts, MFA, invitations, saved items, service inventory, scoped integration credentials, usage controls and evaluation review share one interface.

Architecture

Local models. Explicit access checks.

  1. IngestFastAPI stores immutable originals. A Redis-backed worker extracts, chunks and indexes documents.
  2. RetrievePostgreSQL/pgvector and BM25 search accessible passages. Rank fusion and reranking select evidence.
  3. GenerateOllama runs Qwen locally. A bounded LangGraph agent can also consult permitted inventory and search tools.
  4. VerifyReact streams the answer and opens versioned citations. Revocation is enforced across saved and historical content.
  • React + TypeScript
  • FastAPI
  • PostgreSQL + pgvector
  • Redis
  • Ollama / Qwen
  • LangGraph + MCP
  • Playwright

The application serves frontend and API from one origin, uses revocable personal sessions, and isolates company data with forced PostgreSQL row-level security. Company administrators do not automatically gain access to members' private conversations.
